# Codex 작업 안내 위치

1. 루트 `AGENTS.md`
2. `cheatft_web/AGENTS.md`

새 작업을 시작할 때는 전체 스캔을 하지 말고 `cheatft_web/AGENTS.md`와 `cheatft_web/docs/handoff.md`를 먼저 읽는다. 시작/종료 처리, 백엔드 수정 금지, 문서 갱신, push용 제목/내용 작성 방식은 `cheatft_web/AGENTS.md`를 최신 기준으로 본다.
